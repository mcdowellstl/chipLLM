Heated Landing Zone Temp Sensor Display Error

Step-by-Step Instructions

  1. Inspect the digital readout window on the HLZ holding cabinet to see if a particular error code is active (e.g. `E-1` or `E-2`).
  2. Locate the temperature thermocouple sensor tip inside the cabinet air intake slot.
  3. Clean off any accumulated grease or kitchen residue from the sensor probe head using a warm, slightly damp sanitizing wipe.
  4. Reboot the cabinet power by flipping the dedicated circuit breaker, wait 10 minutes, and check if the temperature readout stabilizes.

Verification Question: Is the HLZ display panel showing a stable temperature readout without error codes?
