Google Edge Server Offline

Step-by-Step Instructions

  1. Locate the main Google Distributed Cloud Edge (GDCE) rack cabinet inside the back office manager workspace.
  2. Verify if the main server chassis status LED indicator light is solid green, blinking yellow/amber, or completely unlit.
  3. Check the physical ethernet cables and link lights on the primary uplink ports connecting the edge server to the store core Cisco switch.
  4. Perform a soft reboot of the GDCE server using the Waystation administrative console interface, or if the local portal is completely unreachable, contact the enterprise remote network operations center.

Verification Question: Is the Google Edge Server status LED back to solid green and communication restored?
