Clear the Paper Jam

Step-by-Step Instructions

  1. Power off the printer using the power button.
  2. Open all access panels and gently pull out jammed paper — always pull toward the paper exit, never backward.
  3. Remove any torn scraps. Use tweezers if needed.
  4. Reload the paper roll so the paper feeds from the bottom.
  5. Close all panels, then power the printer back on.
  6. Print a test page using the button on the back of the unit.
