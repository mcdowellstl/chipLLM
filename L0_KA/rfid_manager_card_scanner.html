POS Manager RFID Scanner Offline

Step-by-Step Instructions

  1. Check the physical USB manager card RFID scanner module attached to the right side of the POS terminal frame.
  2. Disconnect the scanner USB link cable from the terminal's built-in side or bottom port hub.
  3. Ensure the connector plug is clean and dry, then push it back into the terminal port firmly to refresh host connection.
  4. Present a verified-working manager RFID card to see if the green reader LED flashes and prompts for manager login on the POS screen.
